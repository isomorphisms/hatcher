# Implementation plan

## First implementation

Build the triangle construction, valid and invalid motions, a minimal PS emitter, rational-time sampling, rendered stills and independent acceptance. This narrow slice must follow the whole semantic path.

Next qualify the expanding disk and the corrected Venn movie. Then add Casselman's intersections and bounded curves and the Hatcher rational-circle construction.

Do not postpone mathematical identity or throughout-motion invariants while making a visually polished demonstration.

## Allocation

Each Sun job owns an uncertainty that could change the design or acceptance boundary. It stops with evidence and a precise bounded Earth implementation job. Moon handles mechanical propagation only after an exact accepted prerequisite.

Do not send all repetitive implementation through Sun. Do not force every job to have a Moon phase. Shared policy stays in ai-ci, shell preparation in Kitchen and control-plane behavior in Flexible Pipes.

## Milestones and stopping rules

| Milestone | Completion evidence |
| --- | --- |
| M1 construction | Checked triangle, derived PS figure and rejected collinear construction |
| M2 motion | Whole-interval nondegeneracy and expansion; rejected shrinking, midpoint collapse and invalid remapping |
| M3 actual output | Geometry-to-PS trace, rendered stills and decoded movie; targeted serializer/render mutants rejected |
| M4 Venn | Correct universe complement, question identity, undefined empty denominator and lawfully evolving weights |
| M5 linked book construction | Source edition/page confirmed; one parameter causally updates all views and captions |
| M6 follower representation | Native framebuffer/subpixel or GPU path actually consumes the qualified construction, with explicit bounds and target-specific evidence |

Unsupported arithmetic, proof transfer or lowering is a capability gap. Record the smallest concrete gap and its owner; do not silently use an oracle, RefC, generated C, a browser runtime or handwritten shader as the requested implementation.

## Initial exclusions

A standalone general language/compiler, arbitrary nonlinear theorem proving, automatic certification of every imported mesh, a complete PostScript implementation, narration generation, a new media encoder and a full verified hardware stack are outside the first slice.

Retain these as explicit questions where relevant, without treating them as prerequisites for the checked triangle and disk.

## Durable handoffs

Every result records source/compiler identity, assumptions, input/result digests, checked claims, numerical representation, emitted geometry/media, tests actually run, invalid cases rejected, unresolved stages and the next consumer.

Bind build stages to the maintained ICK/NDK policy and qualified pinned Ike where the established build contract selects it. Upstream theorem-prover comparisons are research evidence, not substitutes for the requested Idriç runtime.

No future job is dispatched by this planning packet. It grants no merge, closure, release or physical-device mutation authority.
