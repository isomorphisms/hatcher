# Original Algebraic Topology EPS sources

This directory preserves the complete figure-source set published by Allen Hatcher for *Algebraic Topology*.

- Author page: <https://pi.math.cornell.edu/~hatcher/AT/ATfigs.html>
- Author archive: <https://pi.math.cornell.edu/~hatcher/AT/ATfigures.zip>
- Retrieved: 2026-10-13
- Archive SHA-256: `edbb65e5ce18a48a6adf2fcef20730a88fff38750a74b6d3fe9bcd61dd15c156`
- Imported figure programs: 158
- Imported bytes: 6,337,202

The files retain their archive names and exact bytes under [`original-eps/`](original-eps/). Their names end in `.ps`, while all 158 files begin with an EPSF-3.0 header. No line-ending conversion or source rewriting was performed. [`SHA256SUMS`](SHA256SUMS) records the byte identity of each file.

Only `ATfigures/*.ps` was imported. The archive's `.DS_Store`, `__MACOSX/`, and AppleDouble files are packaging metadata and were omitted.

Hatcher's source page says this set excludes commutative diagrams and some similar diagrams. No additional diagram filtering was applied here.

These programs are the source record for the pictures. Matching each filename to the book's printed page, semantic construction, and editorial inventory ID remains separate work. Copyright remains with the original author; preserving the files here does not relicense them.
